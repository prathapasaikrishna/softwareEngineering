# AI Health Symptom Checker

## Overview
This project predicts possible diseases based on symptoms entered by the user using Machine Learning.

## Features
- Welcome Message
- Dark Mode
- Symptom Prediction
- Disease Prediction
- Health Report Generation
- Charts
- AI Chatbot
- Responsive Design

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install flask pandas numpy matplotlib seaborn scikit-learn
```

## Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
